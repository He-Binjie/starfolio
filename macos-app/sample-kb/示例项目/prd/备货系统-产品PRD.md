# 示例项目：备货系统产品规格说明（PRD）

> 版本：V2.0 · 更新日期：2026-11-12

## 1. 产品定位

帮助供应链计划员在新品上市前完成全国分仓备货测算，将「人工 Excel 估算」升级为「确定性公式 + 参数推荐 + 异常预警」。

## 2. 核心计算规则

1. **安全库存标准**：系统默认将所有区域仓的安全库存设为 **7 天** 销售预测，支持计划员按大区手动微调。
2. **偏差预警阈值**：当实际门店统配量与预测备货量偏差超过 **15%** 时，界面弹出红色预警卡片，要求计划员确认是否重跑模型。
3. **统配外再分配逻辑**：
   - 当部分仓库存不足、总量足够时，自动从盈余仓匀出部分量补齐缺口仓（仅调整采购下单量，非物理调拨）。
   - 当全国总量不足时，按统一安全库存天数等比缩减所有仓库备货量，并要求人工审批确认。

## 3. 验收标准

- 所有计算结果均可追溯到单店预测明细，禁止大模型直接估算具体数值。
- 导出表格字段需与采购系统保持 100% 一致，整箱向上取整。
